v1.1.0 — Power & Battery Telemetry Release Feature Update
Released: 2026-09-15 13:30:00 IST (+05:30)

Added comprehensive hardware tracking for Mac battery metrics, charging input wattage, and power adapter profiles with dual-mode Basic and Advanced telemetry views.

⚡ Power & Battery Subsystem (BatteryPowerService.swift)

  • • Live Battery Percentage & Status: Continuous tracking of battery level (0-100%), charging state, and AC power connection status using IOKit AppleSmartBattery.
  • • Real-time Charging Input Power: Calculates real-time charger input wattage (IPDInputPower), negotiated voltage (IPDInputVoltage), and current (IPDInputCurrent) from connected USB-C or MagSafe adapters.
  • • Power Adapter Telemetry: Profiles connected charger name, manufacturer (Apple Inc.), rated wattage, serial number, firmware revision, and supported USB Power Delivery (USB-PD) profiles.
  • • Battery Health & Maximum Capacity: Computes true maximum health percentage by comparing nominal capacity against factory design capacity (DesignCapacity in mAh), cycle count wear, and condition status.
  • • Physical Sensors & Energy Flow: Real-time battery voltage, instant charge/discharge current (mA), battery power flow (Watts), temperature in °C, and controller model (bq40z651).
  • • Dual-Tier User Interface: Quick glanceable battery chip and charging indicator in MenuBarView with instant toggle to full diagnostic telemetry; dedicated Power & Battery tab in DashboardView.

v1.0.0 — Initial Public Release Milestone 26f7d99
Released: 2026-09-14 17:15:00 IST (+05:30)

The inaugural open-source release of DeskOrbit, unifying external displays, audio DACs, Bluetooth peripherals, and external storage drives into a responsive native macOS menu bar accessory and Home-style dashboard.

🖥️ Display Subsystem (DisplayService.swift)

  • • Apple Silicon DDC/CI: Integrated IOAVService communication over I²C address 0x37 using VCP opcode 0x10 for external monitor hardware brightness.
  • • Apple Native Displays: Native backlight brightness support via private DisplayServices framework for internal Mac displays and Apple Studio Displays.
  • • GPU Gamma LUT Scaling: Linear color lookup table scaling via CGSetDisplayTransferByTable and CGSetDisplayTransferByFormula for non-DDC screens.
  • • Software Dimming Overlay: Floating transparent .screenSaver level overlay window providing click-through dimming across all virtual Spaces.

🔊 Audio Subsystem (AudioService.swift)

  • • CoreAudio Hardware HAL: Real-time volume scalar manipulation using kAudioHardwareServiceDeviceProperty_VirtualMainVolume.
  • • Fast Output Switching: Single-click default audio route switching between internal speakers, USB audio interfaces, and Bluetooth headsets.
  • • Live Hardware Listener: Bound AudioObjectAddPropertyListenerBlock to automatically refresh UI on device disconnect/connect or volume change.

⚡ Bluetooth & External Storage

  • • Battery Monitoring: Extracted power percentages via IOKit IOPSCopyPowerSourcesInfo for connected Bluetooth devices (AirPods, Magic Trackpad, mice).
  • • Drive Capacity Gauges: Volume capacity calculation using NSWorkspace and DiskArbitration displaying used vs. free storage.
  • • Safe Volume Eject: Clean drive unmounting and ejection via NSWorkspace.shared.unmountAndEjectDevice.

📦 Architecture, Packaging & Open Source

  • • Dual-Mode AppKit Architecture: Configured as LSUIElement = true menu bar accessory with dynamic policy elevation to .regular for the dashboard window.
  • • Packaging Scripts: Created bundle_app.sh and create_dmg.sh for automated release compilation and compressed .dmg generation.
  • • CI/CD Pipelines: Created GitHub Actions workflows for automated macOS builds (ci.yml), release assets (release.yml), and Pages deployment (pages.yml).
  • • Community Governance: Published under the MIT License with Contributor Covenant v2.1, Security policies, and AI co-creation provenance disclosure.
