Subsystem Architecture

Direct C and Objective-C framework integration without bloated third-party dependencies.

IOAVService & DDC/CI

Sends VCP opcode 0x10 packets directly to external monitor microcontrollers over Apple Silicon I²C bus 0x37.

CoreGraphics Gamma LUT

Directly manipulates GPU transfer curves using CGSetDisplayTransferByTable for displays without DDC.

CoreAudio & AudioToolbox

Hooks system-wide volume scalar properties and registers listeners on kAudioObjectSystemObject.

SwiftUI & AppKit

Responsive, reactive interface pairing NSStatusItem popovers with floating card grid windows.
